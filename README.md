# CHZZK All-in-One by hanbi

Firefox 우선으로 만든 비공식 CHZZK 통합 확장 프로그램입니다.

## 주요 기능

- GRID/P2P 우회, 1080p 최고 화질 선택 (서버에 1080p가 없으면 최고 가용 화질)
- 식별 가능한 광고 미디어 건너뛰기 및 광고 차단 경고 팝업 숨김 (실방송 검증 필요)
- 녹화 중 청취, 녹화 결과 미리보기, WebM 원본 및 MP4/GIF/WebP 변환·자르기·분할
- 스크린샷 미리보기·저장 (확장 PIP 버튼은 의도적으로 비활성화, Firefox 기본 PiP 사용)
- 통나무 파워 자동 획득·보유량·로그·승부예측 기록
- 확인 가능한 블라인드 채팅 원문 표시
- 실시간 트렌드 썸네일과 팔로잉 방송 hover 영상 미리보기 (무음, 로딩·실패 시 썸네일)
- 로그인 계정의 팔로잉 방송 시작만 표시하는 페이지 내 팝업
- cheese-knife 방식의 HLS 버퍼 보존·강제 라이브 복귀 방지·`buffered` 탐색 (현재 Firefox 실방송 검증 필요)
- 오디오 컴프레서, 밝기·대비·선명도, 채팅·사이드바 보조 기능

## Firefox 설치

`build.ps1`이 만드는 `.xpi`는 ZIP의 복사본인 **미서명 개발용 파일**입니다. 일반 Firefox의 영구 설치에는 Mozilla 서명본이 필요합니다. 서명 전에는 `about:debugging#/runtime/this-firefox`의 **임시 부가 기능 로드**에서 `manifest.json`을 선택해 테스트할 수 있습니다.

영구 설치용 파일은 [Mozilla의 비공개 배포용 서명](https://extensionworkshop.com/documentation/develop/getting-started-with-web-ext/#sign-your-extension-for-self-distribution)으로 만들 수 있습니다. AMO 개발자 계정에서 API 키를 발급한 뒤, 키와 비밀값을 각각 `WEB_EXT_API_KEY`, `WEB_EXT_API_SECRET` 환경 변수로 설정하고 `./sign.ps1`을 실행합니다. 이 스크립트는 현재 소스로 다시 빌드하고 **확장 패키지를 Mozilla에 제출**해 서명본을 `dist/signed-v<버전>/`에 받습니다. 키는 저장소나 패키지에 넣지 않습니다. 스크립트는 Node.js 22 이상과 npm을 사용하며, Firefox 사용 시 별도 프로그램은 필요 없습니다. 서명 심사가 실패하면 AMO 오류를 확인해야 합니다.

서명된 `.xpi`를 Firefox의 `about:addons` → 톱니바퀴 → **파일에서 부가 기능 설치**로 설치합니다. 기존 임시 부가 기능이 켜져 있으면 먼저 제거하고, 설치 후 CHZZK 탭을 새로고침해 이전 페이지 후킹을 없앱니다.

## 1.0.7 화질/GRID 회귀 수정

1.0.5~1.0.6에서 최고 화질 선택을 단순 순서 변경으로 약화한 것을 되돌렸습니다. 480p→1080p 우회는 별도 확장 fetch가 아니라 실제 플레이어 요청을 리다이렉트합니다. 실제 403/404 응답이면 원래 화질 요청으로 복귀하며, 실패한 경로는 60초 동안 재우회하지 않습니다. 네트워크 오류는 다음 재시도부터 원본 경로를 사용합니다.

blob/worker 요청의 문서 출처 판정, 중첩·객체형 재생 JSON 및 축약 P2P 필드 처리를 보완했습니다. 타임머신·녹화·오디오 코드는 이 버전에서 변경하지 않았습니다. 자동 회귀 테스트 통과와 실제 Firefox 방송의 화질 메뉴/GRID 안내 검증은 별개입니다.

## 1.0.6 타임머신 로직 복원

cheese-knife의 `setSeeking`/`patchHls` 구조에 맞춰 MAIN world에서 실제 HLS 컨트롤러를 찾고, 과거 버퍼 보존과 강제 라이브 복귀 억제를 함께 적용합니다. TM 패널·방향키 모두 동일한 `buffered` 탐색 경로를 사용합니다. LIVE·패널 닫기·채널/플레이어 교체 시 원래 설정과 동기화 함수를 복원합니다.

원본과 의도적으로 다른 점: 무제한 과거 버퍼/1,000배 한도 대신 과거 보존 목표를 300초, `maxBufferSize`를 기존 값과 100 MB 중 큰 값으로 설정합니다. 실제 보존 길이는 메모리와 플레이어 동작에 따라 더 짧을 수 있습니다. 연결 실패 시 성공으로 표시하지 않으며 원본 재생을 유지합니다. 이미 버려진 과거 영상을 되살리는 서버 DVR 기능은 아닙니다. **로직 회귀 테스트와 별개로 로그인된 Firefox에서 실제 작동 확인은 아직 필요합니다.**

## 1.0.5 수정 범위와 미확인 사항

- 일반 MP4/`service` 경로를 광고로 오인해 `src`를 지우던 처리와 추측한 타임머신 API 호출·XHR 지연을 제거했습니다.
- 480p→1080p 우회는 후보 재생 목록 및 첫 미디어 세그먼트 접근을 확인한 뒤에만 수행합니다. 목록 요청이 403/404로 바뀌면 원래 요청으로 복귀합니다. Firefox `webRequest`/`webRequestBlocking` 권한을 사용하며 기존 무조건 치환 규칙은 비활성화합니다.
- 팔로잉 알림은 전체 팔로잉 API 목록, 계정별 기준 상태, 탭 간 조회 잠금과 5초 최소 간격을 사용합니다. 처음 관찰한 라이브·계정 전환·오류·오래된 상태는 시작 알림으로 처리하지 않습니다.
- 컴프레서 그래프를 영상별로 재사용하고 동일 모드 재연결을 생략합니다. 연결 실패 시 원음 경로로 복귀합니다.
- 구매 안내는 해당 모달 배경까지 숨기며 가능한 경우 사이트의 닫기 핸들러를 먼저 호출합니다. 다른 모달은 건드리지 않습니다.

**타임머신 완전 복구 및 핵심 4종 실방송 합격을 의미하지 않습니다.** TM 패널은 현재 영상이 제공하는 범위만 탐색합니다. 과거 데이터가 없으면 서버 타임머신을 만들어 내지 못합니다. 문제 방송에서 `TM → 재생 진단 정보`를 펼치면 토큰·쿠키·영상 URL을 제외한 영상 상태와 탐색 범위를 복사할 수 있습니다. 로그인된 Firefox에서 재현 검증은 아직 필요합니다.

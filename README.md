# CHZZK All-in-One
치지직(CHZZK) 방송 시청을 위한 올인원 확장 프로그램입니다. 여러 개의 스크립트와 확장 프로그램을 하나로 통합하여 가볍고 부드럽게 작동합니다. (Manifest V3 100% 호환)

## ✨ 주요 기능
*   **그리드(GRID) / P2P 우회:** 내 컴퓨터 자원을 갉아먹는 치지직 그리드를 강제 차단하고, 일반 서버(HLS)로 강제 연결합니다.
*   **1080p 고정 및 샤픈(Sharpness) 필터:** 화질을 강제로 1080p로 고정하며 화면을 더 선명하게 렌더링하는 필터를 제공합니다.
*   **통나무(파워) 자동 획득:** 방송 시청 시 1시간마다 주어지는 통나무 파워를 백그라운드 API 통신으로 자동 획득합니다. 확장 프로그램 팝업에서 다음 획득 시간과 누적된 로그를 세련된 UI로 확인할 수 있습니다.
*   **화면 속 화면 (PIP):** 치지직 플레이어 하단에 네이티브 PIP 버튼을 추가하여 미니 플레이어로 전환합니다.
*   **화면 캡처 및 녹화:** 현재 화면을 그대로 캡처하거나 녹화하는 버튼을 플레이어 하단에 추가합니다.
*   **채팅 및 UI 개선:**
    *   블라인드 처리된 채팅 원본 복구
    *   방송 시작 팝업 토스트 및 실시간 트렌드 바 제공
    *   불필요한 광고·치트키 안내 팝업 제거

## 🛠 설치 방법 (수동 설치)
이 확장 프로그램은 크롬 웹 스토어에 올라가지 않으며, 개발자 모드를 통해 직접 설치해야 합니다.

**Chrome, Edge, Whale, Firefox 브라우저 적용 방법:**
1. 이 저장소의 코드를 다운로드(ZIP) 한 후 압축을 풉니다.
2. 브라우저 주소창에 `chrome://extensions/` (Firefox는 `about:debugging#/runtime/this-firefox`)를 입력합니다.
3. 우측 상단의 **'개발자 모드'**를 켭니다.
4. 좌측 상단의 **'압축해제된 확장 프로그램 로드'** (Firefox는 '임시 부가 기능 로드')를 클릭합니다.
5. 압축을 푼 폴더(manifest.json이 포함된 폴더)를 선택하면 설치가 완료됩니다.

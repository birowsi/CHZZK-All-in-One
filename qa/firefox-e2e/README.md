# Firefox 실환경 QA

2026-09-28 바탕화면 작업본의 Selenium/Geckodriver 도구를 2026-09-29 원본 프로젝트에 통합했다. 확장 배포물에는 들어가지 않는 개발용 검사다. 기존 결과 JSON과 세션 시작 patch는 당시 기록이며 현재 버전의 합격 증거로 재사용하지 않는다.

## 실행

이 디렉터리에서 `npm ci`로 개발 의존성을 준비한 후 `npm run e2e` 또는 아래 일시정지 검사를 실행한다. Firefox 경로는 `harness.cjs`의 `FIREFOX` 상수다. 별도의 임시 프로필과 임시 확장 설치를 사용하며 사용자의 평소 프로필은 사용하지 않는다. 실제 방송 요청과 미디어 다운로드가 발생한다.

```powershell
$env:HEADLESS = '1'
$env:PAUSE_MINUTES = '6'
node e2e-pause.cjs
```

일시정지 검사는 실제 배포 CHZZK와 로컬 수정판을 함께 검사한다. 시작/끝 한 번의 증가만으로 합격하지 않고, 첫 샘플 이후 관찰 시간의 70% 이상 버퍼가 전진해야 한다. 모든 샘플의 일시정지 위치도 확인한다. 재개 후에는 멈춘 지점에서 진행하는지 검사하고 실패 시 종료 코드 1을 반환한다. 버전별 결과는 상위 `qa/firefox-e2e-pause-results-<version>.json`에 저장한다. 브라우저 메모리 제한·방송 종료·네트워크 오류로 실패할 수 있으므로 결과 내용과 함께 판정해야 한다.

`firefox-e2e-pause-results.json`은 바탕화면에서 가져온 1.1.15 원본 실패 기록이다. 그 기록의 PAUSE-BUFFER 합격 판정은 첫 15초의 증가만 검사하므로 지속 수집을 증명하지 않는다. 같은 코드의 PAUSE-RESUME은 실패했다. `firefox-e2e-pause-results-1.1.15.json`은 1.1.16 버전 번호 반영 직전 수정 후보의 1분 예비 검사로, 원래 1.1.15 배포물 결과가 아니다.

`debug-page.cjs`, `probe-install.cjs`, `perf-run.cjs`는 원 작업본의 조사 도구다. 공식 배포/설치 검증 도구가 아니며 종료 코드만으로 합격 판정하지 않는다. 장시간 성능 검사는 필요할 때 별도로 실행한다. 이번 통합에서는 새로운 의존성 설치 없이 바탕화면에 이미 있던 개발 의존성을 일회성 `NODE_PATH`로 참조했다. 확장 코드와 빌드 결과물은 바탕화면 폴더에 의존하지 않는다.

2026-09-29 정정: 바탕화면의 1.1.15 ZIP은 실제로 `ustar` 헤더를 가진 TAR였다. 당시 XPI 열기 실패를 Firefox 156의 일반적인 `archivePath` 제한이라고 단정한 기록은 근거가 없으므로 사용하지 않는다. 1.1.16 빌드는 ZIP 형식을 명시하고 ZIP reader로 항목과 manifest 버전을 검증한 뒤 XPI로 복사한다.

추가 판정 보강: 전체 평균만으로는 3분 중 마지막 45초 정체도 통과할 수 있어 마지막 4샘플 구간도 별도로 검사하고 `bufferFullError`가 있으면 지속 수집 실패로 처리한다. 모든 샘플을 저장한다. `1.1.16-quota.json`의 최초 PASS 표시는 이 보강 직전 평균 기준의 결과다. 추가 `assessment`와 HLS 오류 기록에 따라 지속 수집은 FAIL로 해석해야 한다. 재개 위치 검사와 XPI 임시 설치 성공은 별도로 유지한다.
